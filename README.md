# Ele Fashion Hub

Next.js + TypeScript + Tailwind CSS storefront foundation for elefashionhub.com.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Included

- Responsive fashion homepage
- Shop/catalogue
- Product detail routes
- Product gallery
- Size/color selection
- Client-side cart with localStorage
- Cart page and order summary
- Nigeria-ready checkout form
- Checkout confirmation flow
- shadcn-style UI primitives
- SEO metadata
- Vercel-ready Next.js structure

## Before going live

Connect:
- Supabase/PostgreSQL for products, customers, carts and orders
- Paystack and/or Flutterwave for live payments
- Webhook verification
- Shipping-rate calculation
- Transactional email
- Admin dashboard
- Real product imagery and catalog data

The current checkout is deliberately a UI/demo flow and does not charge a card.
